One letter that settles coffee vs tea: **A — coffee**. The program writes a
single character, `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else.
Coffee is the livelier stance — mornings, momentum, "but first, coffee" —
so A is the answer with a pulse. A Node 22 program, standard library only,
no input, no network, no clock, no randomness.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Two consecutive runs produce byte-identical output: `out/entry.txt` holds
exactly one byte, `A`, with no trailing newline.
